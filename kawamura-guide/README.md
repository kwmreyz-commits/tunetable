# 川村歯科「治療と費用の道のりガイド」

tunetable とは**別のプロジェクト**です（一時的に同じリポジトリに置いています）。
このフォルダだけを取り出せば、そのまま独立したリポジトリになります。

## 画面

| URL | だれが | 何をする |
| --- | --- | --- |
| `/` | はじめての人 | 道のりと、デンタルドックの説明（公開版） |
| `/plan/new` | 先生・スタッフ | 歯の図から歯をえらんで、見積もりをつくる |
| `/plan#…` | 患者さん | 見積もり（理由 → 治療 → 計算）。QRコード・印刷で持ち帰る |
| `/settings` | 院長・スタッフ | 治療の項目・値段・区分（大人／子ども）を変える |

## 動かし方

```bash
cd kawamura-guide
npm install
npm run dev          # 確認用
npm run dev:phone    # 同じWi-Fiのスマホからも見られる（Network: に出るURLをスマホで開く）
npm test             # テスト
npm run build:public # 公開用ビルド。未確認・未入力があると止まる
```

## 料金や項目の変え方

ふだんは **`/settings` の画面から**変えます（その場で保存）。

- 治療を足す・消す・「扱わない」にする
- 種類（セラミック／ゴールドなど）ごと、区分（大人／子どもなど）ごとの値段
- 値段のつけ方：歯1本ごと／えらんだ歯をまとめて一式／お口全体
- ドックでわかる状態（見積もりに「治療の理由」として出る言葉）
- 支払い方法の表示、メンテナンスの年間回数

設定は**その端末（ブラウザ）の中**に保存されます。サーバーには送りません。
別の端末でも同じ設定を使うときは、「保存と読み込み」から書き出して、読み込みます。

書き出したファイルで `src/data/default-settings.json` を置き換えると、
それが全端末の「最初から入っている設定」になります（公開用ビルドのチェックもこのファイルを見ます）。

## データの置き場所（`src/data/`）

- `default-settings.json` … 最初から入っている料金メニュー（今はすべて仮・未確認）
- `dock.ts` … デンタルドックの説明文と「結果の例」の画像（画像は `public/dock/` に置く）
- `journey.ts` … 道のり4段階の文面と金額
- `modelCases.ts` … 費用の例。院長が決めたら `confirmed: true` に
- `clinic.ts` … 電話・LINE・診療時間・休診日・住所
- 配色は `src/index.css` の `@theme`

## 個人情報

氏名・生年月日・連絡先の入力欄はありません。見積もりの中身は URL の `#` 以降に入り、
サーバーにも端末にも保存されません（保存されるのは料金の設定だけです）。
